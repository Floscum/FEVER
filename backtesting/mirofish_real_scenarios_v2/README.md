## 可以明确看见的产品变化

**合并双方终于分别决策。** 之前国泰君安和海通证券被合并为一个“事件主体”；现在在相同8角色上限内，成为两个独立主体，各有自己的决策与权限约束。输出出现了“中介不参与配套融资承销 → 海通证券要求重新谈判换股比例或筹资结构”的路径。它提供了从被合并方角度核对方案的线索，仍是假设，不能解释为已发生的谈判。

**客户可以做恢复工作。** 旧服务中断案例中，客户仅能沟通、协商或等待，实跑选择WAIT；增加OPERATE后，新实跑选择核实受影响系统、按照已提供文档和脚本恢复。事件主体选择COMMUNICATE，形成“供应商沟通恢复进展—客户执行恢复”的不同职责。这里验证了动作集合能够改变可表达的行为，样本量不足以证明总体质量提升。

**观察清单明确指出哪里需要先核对。** 对新三例的44条条件，最终展示规则离线标记8条：4条数值依据问题、1条短期13F观察问题、3条将未披露消息当作失效的问题。还有分支级的会计比较口径提示。复制时保留原文，以“待核对后使用”标记，避免把它们直接变成可勾选的跟进任务。

这8/44衡量的是审阅支持，不是错误率的完整估计，更不是预测准确率改善18.2%。新规则是从本轮问题发展出来的，存在样本适配、漏报和误报；没有提示的条件也没有经过事实真实性认证。

四个带代码的事件公司都在事实中匹配了名称并具名化。它不等于关键主体全覆盖：Microsoft等支持平台仍可能被归入通用群体。

## 新编译方式为什么没有设为默认

实验依次尝试自由选择少量路径、依据校验、去掉模拟自由文本、逐条暂存并重写。全部使用同三例已封存的模拟输入；旧版本和失败输出保留。第四轮只复用了第三轮首个响应并补齐两次重写，没有重新抽取较好的首轮结果。

| 比较项目（最后一次开发对照） | v7 | v11（含一次重写） |
|---|---:|---:|
| 有非空输出的案例 | 3/3 | 3/3 |
| 可展示分支 | 12 | 5 |
| 最终仍暂存分支 | 0 | 1 |
| 首轮输出中含未匹配数值的分支 | 6/12 | 2/6 |
| 最终展示中含未匹配数值的分支 | 6/12 | 0/5 |
| 展示规则标记的观察条件 | 13/42 | 4/10 |
| 涉及的有效决策角色 | 20/20 | 8/20 |
| 编译调用 | 3 | 5 |
| 编译耗时中位数 | 23.6秒 | 26.9秒 |

v11的“0/5”是校验和暂存规则强制产生的，不是独立质量证明。一个被暂存的“25个交易日”其实存在于F2，但模型只引用了F4，说明拦截原因可能是漏引而非编造。另一些真正无依据的1000万美元、90%、50%条件被阻止进入观察清单，重写后服务中断案例恢复了可展示路径。

内容复核仍发现：

- v11服务中断分支使用了未在输入披露的“复牌后”，观察渠道仍夹带短窗口无法验证交易的13F；
- 部分失效条件只是“未发表意见”“未提供进展”，并未推翻核心传导；
- 机构的目标价调整与实际持仓变化混用，角色职责仍可能错位；
- v7新的比亚迪输出仍提出补充已按口径调整的可比数据，并设了无依据的20%阈值；
- 有些分支从假设直接跳到“迫使对方调整”，影响关系的强度仍缺乏依据。

因此没有扩大到预备的24例，也没有把原始数值问题减少写成“更有用”或“更准”。后续优先收紧公开观察渠道、交易状态和真正相反的失效信号；不会只用角色覆盖率或漂亮的字段数量判断效果。

## 怎么理解多智能体的意义

当前证据最适合支持三个用途：让利益不同的参与方分别表达约束；把同一事件拆成不同职责与条件响应；生成需要继续查证的研究线索。合并案的被合并方议价、故障案的客户恢复，都是可以直接检查的实例。

本轮没有单智能体对照、没有独立人工评分、没有股价或收益回测，不能据此宣称多智能体优于单智能体。实际使用更适合把它作为“还漏了谁、谁能做什么、下一步查什么”的辅助工具。
