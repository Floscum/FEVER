# 互动轨迹消融 v1：可移植结果包

12 个案例，比较情景汇总时保留或隐藏原始互动记录；两组共用互动后形成的结构化决策。
保留组质量均分 8.21/20，隐藏组 10.04/20。标签重复一致性不足，预注册结论为不确定。
这不是对完全移除模拟的实验，也不评价股价或交易收益。

运行 `python3 verify_results.py` 即可验证全部校验和，并从逐案例的两次评分重新计算
质量均分、严格合格率和重复一致率。无需模型密钥、网络或额外依赖。

`cases/` 包含匿名共用输入、两组情景和原始布尔/数值评分；`manifest.json` 保留协议、
原始输入哈希与展示输入的转换规则。原始运行路径、证券标识和具体事件日期不随包分发。
费用与延迟保留为原封存账本的汇总数，本验证器不独立重建供应商费用或运行耗时。
质量指标属于旧 v6 实验，不能用来宣称产品 v7 的质量提高。
